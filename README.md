## The entry

Exactly one word — the first word that came to mind, no topic, no
explanation, no second draft:

> **snollygoster**

A shrewd, unscrupulous schemer. Surprising, vivid, and with a spark of
wit in its sound — the kind of word a lexicographer picks over safe
filler.

## How it works

`main.py` is pure Python standard library. It writes the single word to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No
network, no model calls, no dependencies.

```sh
python3 main.py
cat /output/entry.txt
```
